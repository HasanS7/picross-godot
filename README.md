# Picross

A simple grid-based puzzle game built with Godot Game Engine

The game generates and displays a 2D grid of buttons that the player can interact with to solve puzzles.
The player must figure out the exact pattern of the image using the numbers to complete the level.
The game includes a main menu, difficulty selection, custom puzzle settings, and support for loading puzzle levels from JSON files.
